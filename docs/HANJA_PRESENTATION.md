# 한자 변환 표기 설정

입력기 설정 → 한자 변환 → **변환 표기**에서 선택합니다. 기본값은 기존과 같은 **한자**입니다.

| 설정 | 학교 | 학교에 |
|---|---|---|
| 한자 | 學校 | 學校에 |
| 한글(한자) | 학교(學校) | 학교(學校)에 |
| 한자(한글) | 學校(학교) | 學校(학교)에 |
| 한글한자 | 학교學校 | 학교學校에 |

`안녕하다`는 `안녕(安寧)하다`처럼 변환되는 부분만 병기하며 조사·어미·주변 인용부호는 밖에 남깁니다. 원문 후보와 한자 후보의 순서, 교육용/KS 자형 선택, 이체자·벽자 구분을 유지합니다. 기호·이모지·날짜·단위·로마자 후보에 이 병기 방식을 적용하지 않습니다.

선택은 입력기 설정에 저장되고 헬퍼에 전달됩니다. 변경 이후 새로 생성하는 한자 후보부터 적용됩니다. 입력 내용은 기록하지 않습니다.

이 기능은 개발 소스에 추가했으며 기존 0.4.7 설치 파일에는 포함되지 않습니다. 사용자의 개발 방식 요청에 따라 매 변경마다 설치·배포하지 않고 기능을 누적합니다.

검증: 네 가지 표기, 조사·어미·인용부호 보존, 기본 원문 후보, 자형·후보 순서, 설정 전환·유지, 잘못된 설정 거부를 검사하는 15개 시험 통과. 전체 Python 1,166개 통과·선택 항목 11개 건너뜀, 전체 macOS Swift 소스 typecheck 통과. 전체 Python 시험 결과는 `build/hanja-presentation/full-python-tests.log`에 보존합니다.
