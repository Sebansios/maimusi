# 매무시 0.5.0 Beta 1 배포 안내

배포 담당자용 메모와 웹사이트에 그대로 옮길 수 있는 문구입니다.

## 배포 파일 (`build/dist/`)

| 파일 | 용도 |
|---|---|
| `Maimusi-0.5.0-beta1.pkg` | 기본 다운로드. 설치 프로그램 하나 |
| `Maimusi-0.5.0-beta1-macOS.zip` | pkg + README.txt + LICENSE.txt + THIRD_PARTY_NOTICES.md + uninstall.command |
| `SHA256SUMS` | 두 파일의 SHA-256 |

- 서명: ad-hoc(Apple Developer ID 없음), 공증 없음. 웹에서 받으면 첫 실행 때 Gatekeeper 경고가 나온다.
  Developer ID 개인 계정은 인증서에 법적 실명이 표시되므로 실명 비공개 원칙과 충돌한다(법인 계정만 회피 가능).
- 대상: Apple Silicon, macOS 13 이상. 설치 프로그램이 Intel Mac에서는 안내 문구와 함께 설치를 막는다.
- 포함하지 않은 것: NIKL로 학습한 경량 모델과 경계 보정 모델([현재 모델 배포 범위](../LICENSING.md)).
- 개인정보 검사: 실명·개인 메일·로그인 이름·홈 경로를 검사어로 앱, pkg(전개), zip을 검사해 통과.
  검사어는 실행 시 환경 변수로만 넘기고 저장소에 적지 않는다.

## 웹사이트

- 배포 페이지: https://www.sebansios.com/maimusi (journal repo `src/pages/maimusi.astro`, 현재 준비 중 안내만)

### 매무시 — 한글 자동 띄어쓰기 입력기 (베타)

띄어쓰기 없이 입력하고 스페이스를 누르세요. 찰떡 엔진이 문장 전체를 알맞게 띄어 줍니다.
어느 앱에서나 일반 한글 입력기처럼 쓸 수 있고, 변환 중에는 한자·이모지·기호 후보도 고를 수 있습니다.

- 입력한 내용은 저장하거나 외부로 보내지 않습니다. 모든 처리는 Mac 안에서 이루어집니다.
- 요구 사항: Apple Silicon(M1 이후) Mac, macOS 13 Ventura 이상
- 버전 0.5.0 Beta 1 · 무료

**[다운로드 (.pkg, 약 96MB)]** · [설명서와 제거 도구 포함 (.zip)]

**설치할 때 경고가 나오면**
베타 버전은 아직 Apple 공증을 받지 않아 "Apple이 악성 코드가 없음을 확인할 수 없습니다"라는 창이 뜹니다.
[완료]를 누른 뒤 **시스템 설정 › 개인정보 보호 및 보안**에서 [그래도 열기]를 누르면 설치를 계속할 수 있습니다.

메뉴 막대의 입력 메뉴에서 **매무시 (두벌식)**을 선택하세요. 목록에 없으면 시스템 설정 › 키보드 › 입력 소스에서 추가합니다.
