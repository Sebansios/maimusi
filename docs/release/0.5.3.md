# 매무시 0.5.3

2026-11-10 (시험 빌드 30, 미배포)

- macOS 후보 창 테마. 설정 › 후보 창에서 프리셋을 고르고 세부 항목을 바꿀 수 있다.
  - 프리셋: 유리(기본), 옻칠(흑칠 바탕·주칠 선택), 한지, 먹, 청자, 가로, 담백, 기본(0.5.2).
  - 세부 조정: 모서리(스퀘어클·둥근·각진)와 반지름, 배경(시스템 반투명 재질·Liquid Glass·투명 유리·단색), 색(바탕·테두리·글자·보조 글자·선택·선택 글자), 글꼴과 크기, 선택 표시(채움·밑줄·막대), 세로·가로 배열, 여백, 번호·설명·경계 조정 키·키 안내 표시.
  - 프리셋에서 한 항목이라도 바꾸면 「사용자 지정」으로 저장한다.
  - 「유리」는 macOS 26 이상에서 Liquid Glass(`NSGlassEffectView`)를 쓴다. 그 전 macOS에서는 스퀘어클(연속 곡률 모서리, 시스템 반투명 재질)로 그린다. 시험 빌드 29의 「스퀘어클」 프리셋은 「유리」로 합쳤다.
- 글자 크기 설정(보통·크게·아주 크게). 모든 테마에 적용한다.
- Shift+Space는 일반 두벌식처럼 친 그대로 확정하고 공백을 넣는다(자동 띄어쓰기 없음). 자동 띄어쓰기를 잠시 쓰지 않는 방법이며 따로 끄는 단축키는 두지 않는다. 전에는 조합 중인 문장 안에 공백만 넣었고, 설정 「직접 넣은 공백」은 없앴다. macOS·Windows 공용 코어 변경.
- 설정 「띄어쓰기 규칙」에 예문. 규칙을 바꾸면 「국어사전을펴놓고사과10개를먹어보았다」가 어떻게 띄어지는지 바로 보이고, 직접 문장을 넣어 볼 수 있다(찰떡 엔진).
- 단어장 내보내기·가져오기와 기기 사이 동기화. 설정 「기기 사이에 단어장 맞추기」에서 폴더(iCloud Drive·Google Drive·Dropbox·OneDrive·외장 디스크 등)를 고르면 그 안의 `Maimusi` 폴더에 기기마다 단어장 파일을 두고 다른 기기의 것과 합친다. 세반시옷 서버는 거치지 않는다. 형식: docs/WORDBOOK.md.
- 경계 기억 안전장치. 한 번 고치면 바로 기억하되, 암호 칸·주소·메일·경로가 섞인 글·한글이 없는 말은 기억하지 않는다. 기억한 띄어쓰기가 쓰인 문장은 후보 창 아래에 「기억한 띄어쓰기」로 알리고, 입력 메뉴 「방금 기억한 띄어쓰기 잊기」와 설정의 기억 목록에서 하나씩 지운다.
- 설정 「개인정보」: 이 Mac에 남는 것, 받아 둔 글꼴(지우기), 기기 밖으로 나가는 것을 한곳에. 사용권 계약 제4조에 단어장 동기화 폴더 문장 추가.
- 훈음으로 한자 찾기(선택, 기본 꺼짐). 「살찔비」 → 肥, 「배울학학교교」 → 學校. 켜면 이런 입력은 띄어 쓰지 않는다. 사전에 있는 낱말(입구 → 入口)이 훈음(口)보다 먼저.
- 경계 조정을 ⇧←(줄이기)·⇧→(늘리기) 두 키로 정리. 후보 창 아래 줄은 키캡과 이름만 보이고, 지금 쓸 수 없는 쪽은 흐리게 둔다. 「앞과 합치기」「뒤와 합치기」 단추는 없앴다. 늘리기로 다음 어절을 다 가져오면 합쳐지고, 앞 어절과는 ←로 옮긴 뒤 ⇧→. 다른 단축키와 겹치지 않도록 합치기 전용 키는 두지 않는다.
- 후보 창 기본 글꼴: Noto Sans CJK KR(본고딕), 한지 테마는 Noto Serif CJK KR(본명조).
  - 앱에는 부분 글꼴만 넣었다. 한글, 로마자 표기용 라틴 문자, 문장 부호·기호, KS X 1001 한자 4,888자. 설치 파일 약 10 MB 증가.
  - 같은 글꼴이 이미 설치돼 있으면(Noto Sans/Serif CJK KR, Source Han Sans/Serif K·KR, 본고딕·본명조) 그것을 쓴다.
  - 부분 글꼴에 없는 한자가 후보에 처음 나오면 같은 글꼴의 전체 파일(16–25 MB)을 `dl.sebansios.com`에서 한 번 받아 크기·SHA-256을 확인한 뒤 쓴다. 입력한 내용은 보내지 않는다. 설정 「확장 한자 글꼴 자동으로 받기」로 끌 수 있다.
  - 글꼴 사용권: SIL Open Font License 1.1. 앱 안 `Licenses/fonts/NotoCJK-OFL.txt`.
- 한자 자형 설정을 고르면 그 자형만 낸다(교육용이면 強, KS면 强). 전에는 다른 자형도 후보 아래쪽에 냈다. 교육용 𮕩(확장 F)처럼 흔한 글꼴에 없는 글자만 다른 자형(衰)을 함께 낸다.
- 한자 후보 설명에서 「한자 ·」 머리말 삭제. 뜻과 음만 보인다(學校 → 배울 학, 학교 교). 벽자·자형 표시는 뒤에 붙는다. 두음 법칙 소리로 찾은 글자는 본음 훈음만 적는다(理解 → 다스릴 리, 쪼갤 해).
- 하다 동사의 줄어든 활용형 한자 변환 수정. 위한·위해·위할·위함 → 爲한·爲해·爲할·爲함. 낱말 전체가 사전의 다른 한자어(胃寒, 危害)와 같아도 찰떡 엔진(Kiwi)이 하다 동사로 읽으면 그 한자를 먼저 낸다. 한 글자 어근은 흔히 쓰는 한자를 먼저(對한, 因해, 依해, 通해). 피해·이해 같은 명사는 그대로.
- 한글 낱자 변환 후보에 반각 한글 추가. ㄱ → ﾡ, ㅋㅋ → ﾻﾻ, 반각은 호환 자모로. 경량 엔진에서도 나온다.
- 개인정보 안내와 사용권 계약 제4조를 macOS 글꼴 받기에 맞게 수정. Windows 판은 그대로 네트워크에 연결하지 않는다.
- macOS 자동 업데이트. 하루 한 번 `dl.sebansios.com/maimusi/update/macos.json`을 받아 서명(Ed25519, 앱에 넣은 공개키)을 확인하고, 지금보다 높은 빌드면 화면 오른쪽 위에 알림을 띄운다. 알림은 키보드 초점을 가져가지 않고 타자가 멈춘 뒤에 나온다. 「업데이트」를 누르면 설치 파일을 받아 서명된 크기·SHA-256과 대조한 뒤 macOS 설치 프로그램으로 연다. 「나중에」는 하루 뒤 다시, 「이 버전 건너뛰기」는 다음 판부터 알린다. 입력 메뉴 「업데이트 확인…」과 설정 › 정보 「지금 확인」으로 직접 확인하고, 「새 버전 자동으로 확인」으로 끈다. 요청에는 입력 내용·쓰는 판·기기 정보를 싣지 않는다(User-Agent `Maimusi`, 언어 머리글 고정). 형식·출시 순서: docs/UPDATES.md. 이 기능은 이 판부터 들어가므로 0.5.2 이전 사용자는 한 번 직접 설치해야 한다.
- 글꼴 받기 요청의 Accept-Language 머리글을 고정값으로(시스템 언어 설정을 알리지 않는다).


## Windows 판(빌드 33, 시험 빌드, 미배포)

macOS 0.5.3에서 정한 것 가운데 Windows에 옮긴 것. 공용 코어·엔진 변경(Shift+Space, 낱자 반각 한글, 한자 설명·하다 동사·자형, 훈음 찾기, 학습 거르기)은 그대로 들어 있다. 글꼴 받기와 Noto CJK 부분 글꼴은 macOS에만 있고, Windows는 네트워크에 연결하지 않으며 시스템의 맑은 고딕을 쓴다.

- 후보 창을 macOS와 같은 모양으로 바꿨다(빌드 33). 설정 「후보 창」에서 같은 프리셋(유리·옻칠·한지·먹·청자·가로·담백·기본(0.5.2))과 글자 크기를 고르고 미리보기로 본다. 스퀘어클 모서리, 선택 표시(채움·밑줄·막대), 번호·설명·키캡 경계 조정·「기억한 띄어쓰기」·쪽 번호의 배치가 macOS와 같다. Windows에는 Liquid Glass와 반투명 재질이 없어 「유리」 등은 뒤 화면을 흐리게 비추지 않는 반투명 바탕으로 그린다. 세부 조정(사용자 지정)은 아직 없다.
- 후보 창·설정·입력 표시기 글꼴을 맑은 고딕으로 바꾸고(한지 테마는 바탕) 설치 파일에서 Noto Sans KR을 뺐다(빌드 33).

- 설정 「직접 넣은 공백」을 없애고, 「띄어쓰기 규칙」에 Shift+Space 안내와 예문(「국어사전을펴놓고사과10개를먹어보았다」, 직접 넣어 볼 수 있음)을 두었다. 예문은 찰떡 엔진이 지금 규칙으로 띄운다.
- 후보 창의 경계 조정은 ⇧← 줄이기·⇧→ 늘리기 두 항목만 남겼다(「앞과 합치기」「뒤와 합치기」 삭제). 쓸 수 없는 쪽은 흐리게 둔다.
- 「한자 변환」에 「훈음으로 한자 찾기 (살찔비 → 肥)」(기본 꺼짐). 자형 안내를 「고른 자형만 후보에 나옵니다…」로 고쳤다.
- 경계 기억 안전장치: 문서의 입력 범위(InputScope)가 암호·PIN·메일·로그인 이름·URL·숫자·전화번호·한 글자 칸이면 기억하지 않는다. 기억한 띄어쓰기가 쓰인 문장은 후보 창 아래에 「기억한 띄어쓰기」로 알리고, 입력 표시기 메뉴 「방금 기억한 띄어쓰기 잊기」와 설정의 기억 목록에서 하나씩 지운다.
- 단어장 내보내기·가져오기와 「기기 사이에 단어장 맞추기」(고른 폴더의 `Maimusi\`, macOS와 같은 형식). 앱마다 뜨는 입력기와 설정 앱이 한 번에 하나씩 맞춘다.
- 설정 「개인정보」: 이 PC에 남는 것(설정·단어·기억한 띄어쓰기, 「설정 파일 보기」), 기기 밖으로 나가는 것(없음, 또는 고른 동기화 폴더), 백업 안내.
- 설정 창이 화면보다 길면 세로로 스크롤한다. 단어장·맞추기 칸의 빈 줄을 없앴다.
