# 단어장 파일 형식

매무시의 등록한 단어와 기억한 띄어쓰기를 담는 JSON 파일. 내보내기·가져오기와 기기 사이 동기화에 같은 형식을
쓴다. macOS(`macos/Sources/Wordbook.swift`)와 Windows(`windows/common/wordbook.cpp`)가 0.5.3부터 같은 형식을 읽고 쓴다. 시각은 두 판 모두 초 단위로 적고(소수 없음), 기기 안에서는 소수까지 기록한다.

```json
{
  "format": "maimusi-wordbook",
  "version": 1,
  "device": "c2ee64a7",
  "updated": "2026-11-10T05:30:18Z",
  "words": [
    {"word": "찰떡엔진", "at": "2026-11-10T05:31:18Z"},
    {"word": "지운단어", "at": "2026-11-10T05:32:00Z", "removed": true}
  ],
  "boundaries": [
    {"compact": "먹어버렸다", "spaced": "먹어 버렸다", "at": "2026-11-10T05:31:18Z"}
  ]
}
```

- `format`은 반드시 `maimusi-wordbook`. `version`이 더 크면 읽지 않는다.
- `device`: 동기화 파일에만. 기기 이름이 아닌 무작위 8자리(설정 `deviceID`). 내보낸 파일에는 없다.
- `at`: 그 항목을 마지막으로 바꾼(더하거나 지운) 때, ISO 8601 UTC.
- `removed: true`: 지운 항목. 동기화 파일에만 넣는다. 지운 기록은 1년 뒤 버린다.
- 단어: 2–40자, 공백 없음, 글자·숫자와 `-·’'`만. 띄어쓰기: `spaced`에서 공백을 빼면 `compact`, 연속 공백 없음.
  이 조건에 맞지 않는 항목은 읽을 때 버린다.

## 가져오기

덮어쓰지 않고 더한다. 없는 단어와 띄어쓰기를 더하고, 같은 `compact`의 띄어쓰기가 다르면 파일 쪽이 더 나중일
때만 바꾼다. 파일의 지운 기록은 따르지 않는다.

## 동기화

사용자가 고른 폴더 안의 `Maimusi/`에 기기마다 `maimusi-wordbook-<device>.json` 하나만 쓴다. 기기는 자기 파일만
쓰므로 클라우드 서비스의 충돌 사본이 생기지 않는다. 같은 폴더의 다른 `maimusi-wordbook-*.json`을 읽어 항목마다
`at`이 더 나중인 쪽을 따르고(같으면 남아 있는 쪽), 결과를 자기 파일에 쓴다. 맞추는 때: 입력기 시작, 단어·기억이
바뀐 3초 뒤, 5분마다, 설정의 「지금 맞추기」. iCloud Drive가 아직 내려받지 않은 파일(`.이름.icloud`)은 내려받기를
요청하고 다음에 읽는다. 세반시옷 서버는 쓰지 않는다.

Windows는 앱마다 입력기가 따로 떠서 `settings.json`을 여럿이 고친다. 맞추기는 이름 있는 뮤텍스
`Local\MaimusiWordbookSync`로 한 번에 하나만 하고, 다른 기기 파일을 합친 결과를 설정 뮤텍스 아래에서
`settings.json`을 다시 읽어 그 사이의 변경과 한 번 더 합친 뒤 쓴다. 주기 맞추기는 입력하는 앱의 입력기가
포커스를 받을 때, 마지막으로 맞춘 지 5분이 지났으면 한다(샌드박스 앱은 하지 않음). OneDrive 「파일
주문형」으로 내려받지 않은 파일은 읽으면 내려받고, 읽지 못하면 다음에 다시 읽는다. 자체 시험:
`MaimusiSettings.exe --test-wordbook [폴더]`(사용자 설정은 건드리지 않음).
