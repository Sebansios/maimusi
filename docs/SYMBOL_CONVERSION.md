# 기호·문자 변환 (0.4.7)

기호를 입력하거나 이름을 쓴 뒤 Space로 변환 상태에 들어가고, Space 또는 ↑/↓로 후보를 고릅니다. 숫자 키·마우스로 후보를 선택하고 Enter로 확정합니다. 원문도 후보로 남습니다. 기호를 선택하기 전에는 자동으로 특수문자를 삽입하지 않습니다.

| 입력 | 대표 후보 |
|---|---|
| `/`, `가운뎃점` | `·` (첫 후보), `ㆍ`, 전각 빗금 |
| `[`, `]`, `(`, `)`, `{`, `}` | 여는/닫는 소괄호·대괄호·낫표·화살괄호·전각 괄호 |
| `'`, `"` | 곡선 따옴표·낫표 |
| `괄호` | `()` `[]` `{}` `〈〉` `《》` `≪≫` `「」` `『』` `【】` `〔〕` `（）` `［］` `｛｝` 및 따옴표 쌍 |
| `[책 이름]`, `(내용)`, `'내용'` | 내용을 보존하며 `『책 이름』`, `「내용」` 등으로 변환 |
| `홑낫표`, `겹낫표`, `겹화살괄호`, `따옴표` | 해당 괄호·인용부호 쌍 |
| `알파`, `오메가`, `대문자알파` | `α/Α`, `ω/Ω`, `Α` (그리스 문자 24개 이름) |
| `화살표`, `수학기호`, `선문자`, `도형`, `음표` | 해당 문자 목록 |
| `원문자`, `로마숫자`, `분수`, `단위기호`, `동그라미15` | 번호·숫자·단위 기호와 `⑮` |
| `그리스문자`, `라틴문자`, `키릴문자`, `히라가나`, `가타카나` | 해당 문자 목록 |

이미 확정한 `[책 이름]` 전체도 선택 후 Control+Shift+R로 재편집할 수 있습니다. 이름은 정확히 일치할 때 찾으며 `오메가3`, `알파벳`, URL 안의 `/`를 이름 변환으로 바꾸지 않습니다. `대문자알파`, `특수문자` 같은 변환 이름은 자동 띄어쓰기로 둘로 나누지 않습니다.

## 선택 옵션

입력기 설정 → 기호 변환 → **자음으로도 특수문자 목록 열기**는 기본 꺼짐입니다. 켰을 때만 `ㅁ`, `ㄷ`, `ㅎ` 등 자음으로 기존 한자키와 유사한 특수문자 목록을 열 수 있습니다. 이름·키보드 기호 변환은 이 옵션과 무관하게 제공됩니다. Windows 후보의 정확한 순서·모든 확장 문자와의 일치를 보장하지 않습니다.

한국 문자 집합 KS X 1001의 부호·전각·자모·문자 행은 표준 EUC-KR codec에서 생성합니다. CP949의 같은 행으로 독립 대조하며 공백·보이지 않는 soft hyphen·Hangul filler는 제외합니다. 각 이름별 목록으로 전체 범위를 찾습니다. 통합 `특수문자` 목록은 공통 후보 상한(원문 포함 512)까지만 표시합니다. 네트워크·개인 입력 저장 없이 기존 엔진에서 처리합니다.

## 검증

- Python 1,151개 통과·선택 항목 11개 건너뜀. 신규 기호·그리스 이름·원문 보존·자음 기본 꺼짐/활성/해제·정확한 이름 유지·긴 목록 검사 포함.
- Rust 62개, AppKit 실제 NSTextView 검사 41개 통과. `/`와 여는 괄호의 조합 유지→후보 선택→확정, Esc 취소·Backspace, 공백이 있는 괄호 전체의 변환을 확인.
- 실제 동결 헬퍼 311요청과 소스 응답 일치. 기호·옵션 전환·한자 및 기존 띄어쓰기, 로컬 학습 모델 해시·건강 상태 확인.
- 앱 자가 시험은 실제 번들 헬퍼와 C ABI 세션에서 기호·그리스 문자·괄호 후보와 `/→·` 확정을 확인. ad-hoc 서명·라이선스·패키지 개인정보 검사 통과.
- 기존 0.4.6 학습 모델·띄어쓰기 정책 유지. 54,117문장 평가 결과는 비공개 연구 기록에 보존. 본 기호 변환의 기능 시험을 언어 정확도로 일반화하지 않음.

규범 부호의 구분은 [국립국어원 문장 부호 해설](https://www.korean.go.kr/front/etcData/etcDataView.do?etc_seq=431&mn_id=&pageIndex=1)과 [한국어 어문 규범](https://korean.go.kr/kornorms/m/m_regltn.do)을 참고했습니다. [Microsoft Korean IME](https://learn.microsoft.com/en-us/globalization/input/korean-ime)는 Windows 한자 변환의 사용자 동작 참고 자료이며 이 코드의 문자 테이블 출처는 아닙니다.

## 후속 작업

한글로 입력한 외래어를 원어로 바꾸는 사전 기반 후보를 추가합니다. 발음만으로 원어를 추측해 확정하지 않으며 언어·중의성을 표시하고 기존 한자·기호·이모지·단위 후보보다 상당히 아래에 배치합니다. 이번 버전에 원어 사전 기능을 넣지 않습니다.
