# 소스와 배포 범위

이 저장소에는 공용 코어·엔진, 운영체제별 어댑터, 테스트·개발 도구,
설치 템플릿과 제품 문서를 포함합니다. 자체 소스·문서는 [기본 저작권 유지](../LICENSE)
(All rights reserved)로 공개하며, 현재 별도의 오픈소스 이용 허락을 부여하지 않습니다.
현재 배포 패키지의 EULA와 제3자 조건은 [라이선스 안내](LICENSING.md)를 참고하세요.

## 포함하지 않는 자료

에이전트 지침과 실행 상태, 기기별 설정, 내부 인수인계·실험 기록,
개인정보, 인증정보와 서명 개인키, 학습 말뭉치와 제한된 모델,
빌드 산출물·가상환경·cache는 Git에 넣지 않습니다.

`models/`에는 준비 안내만 있습니다. 모델의 제품 배포 허용 범위를
소스 저장소의 재배포 허가로 확장하지 않습니다.
제3자 코드·데이터에는 원래 저작권 고지와 라이선스를 유지합니다.
업데이트 검증용 **공개키**와 제품의 공개 문의 주소는 소스에 포함합니다.

## 공개 소스 검사

```sh
python tools/public_source.py audit
python tools/public_source.py export --output <새로운-로컬-폴더>
```

`tools/public-source.json`이 허용 경로 목록입니다. 새 최상위 경로를 추가할 때는
공개 가능한 자료인지 검토한 뒤 목록을 갱신합니다. audit은 추적 파일과
ignore되지 않은 새 파일의 금지 경로·개인정보 표식·인증키 패턴·symlink를 검사합니다.
실패한 위치만 표시하고 일치한 비밀값을 출력하지 않습니다.

export는 작업 트리와 index가 깨끗할 때 검증한 HEAD의 파일만 새 폴더로 내보냅니다.
기존 폴더를 덮어쓰지 않으며 `.git`, 이전 커밋·작성자·태그·원격 설정을 복사하지 않습니다.
자동 검사는 모든 비밀의 부재나 자료의 재배포 허가를 증명하지 않습니다.
출처·권한·개인정보와 파일 목록은 공개 전에 함께 검토합니다.

`.gitignore`는 이미 추적된 파일을 숨기지 않으며, `export-ignore`는 Git 이력이나
push에 적용되지 않습니다. 참고: [gitignore](https://git-scm.com/docs/gitignore),
[gitattributes](https://git-scm.com/docs/gitattributes).
